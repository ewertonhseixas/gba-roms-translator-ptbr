# 📜 Suíte do Protocolo de Tradução e Localização (PT-BR)

Este diretório concentra a metodologia canônica, diretrizes gramaticais, políticas de neutralidade de gênero, controle de métricas e convenções de terminologia para a localização de ROMs retrô em Português Brasileiro (com foco principal em Game Boy Advance e arquitetura extensível para SNES, Mega Drive, NDS e PS1).

## ⚡ Como Usar este Protocolo

1. **Ao Traduzir Novos Lotes:** Consulte o protocolo mestre para assegurar que cada personagem mantenha sua voz e que nenhuma linha de diálogo exceda a zona operacional recomendada (**1 a 32 caracteres**, tolerância máxima de 35).
2. **Ao Criar Novos Jogos:** O template padronizado de protocolo de tradução já é carregado automaticamente na pasta `docs/` de novos projetos gerados a partir de `jogos/_MODELO_NOVO_JOGO/`.
3. **No Processo de QA / Revisão:** Utilize a checklist de liberação rápida da Seção 5 do protocolo antes de compilar a ROM final.
